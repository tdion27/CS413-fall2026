# Assignment 1 Reflection

In this assignment, I had to use AI to translate a program that solved an
n-queens problem. The AI was successfully able to look at the program and
translate it into Python with only a simple prompt. It also noticed that there
was an issue with translating the ATS backtracking state to immutable Python
tuples. It correctly caught a recursion error and changed course with the
implementation.

The AI was also able to verify its own work and complete a second pass through
the code with the use of another prompt. Manually reviewing the code ensured
that I understood what the code was doing and that the AI translated the
program correctly. I believe that this manual review of the code is an
important and mandatory part of AI-assisted development. With my name attached
to the code, I need to ensure that I understand what it is doing and how it
works.

Overall, working with an AI agent to complete this assignment shows how a
developer can work with a new programming language that they might not have
encountered before. The AI can help translate code into a language that the
developer does know how to work with, after which the developer can review the
code to ensure that it works as intended. Overall, this was a very simple
process made very easy with the use of AI tools.
